# Security Policy

We take security and vulnerabilities seriously at Yuva Samrajya. We appreciate any reports identifying configuration exposures, database leaks, or code issues.

---

## 🛡️ Supported Versions

We actively monitor and patch the following versions:

| Version                 | Supported |
| :---------------------- | :-------- |
| `0.1.x` (Main / Stable) | ✅ Yes    |
| `< 0.1` (Deprecated)    | ❌ No     |

---

## 🔒 Reporting a Vulnerability

Please **do not** create public issues to report security vulnerabilities.

Instead, report them privately:

1. Email us at **security@yuvasamrajya.org**.
2. Include steps to reproduce, potential impact on user profiles, and test accounts used.
3. We will acknowledge receipt of your report within 48 hours and work with you to coordinate disclosures/patches.
